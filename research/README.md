# Research workbench

`research/` houses source investigations and verification; **canonical human-readable records are in [`notes/`](../notes/README.md)**.

- [Bibliography](bibliography/README.md): editions, sources, citation inventory.
- [Source notes](source-notes/README.md): scholarly comparisons and uncertainty.
- [Verification queue](verification/README.md): scene checks and attribution questions.

The old `philosophers/`, `books/` and `concepts/` directories have been retained as redirects to their canonical note categories rather than as locations for duplicate documents.

**Public repository warning:** everything outside `docs/` remains publicly readable on GitHub. The maximum current story boundary is S01E06, including in file names, research notes and headings.
